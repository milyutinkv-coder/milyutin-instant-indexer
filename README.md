# Milyutin Instant Indexer

WordPress-плагин для мгновенной отправки новых и обновлённых записей на индексацию:

- **IndexNow** → Яндекс, Bing, Naver, Seznam (один запрос — все участники протокола);
- **Google Indexing API** → Google, через ваш собственный сервисный аккаунт Google Cloud.

Автор: **Константин Милютин** · [milyutin-codes.ru](https://milyutin-codes.ru) · [Группа ВКонтакте](https://vk.com/milyutin_codes)

## Установка

1. Скопируйте папку `milyutin-instant-indexer` в `wp-content/plugins/`
   (или заархивируйте её в ZIP и загрузите через «Плагины → Добавить новый → Загрузить плагин»).
2. Активируйте плагин в админке. При активации автоматически создаётся ключ IndexNow,
   регистрируется правило ЧПУ и планируются задачи WP-Cron.
3. Откройте меню **Instant Indexer** и следуйте инструкции на странице настроек
   (раздел «Инструкция по настройке» — там пошагово про IndexNow и Google).

Требования: WordPress 5.8+, PHP 7.4+, включённые «красивые ссылки» (или права на запись
в корень сайта для физического файла ключа), расширение OpenSSL для шифрования JSON Google.

## Структура

```
milyutin-instant-indexer/
├── milyutin-instant-indexer.php   # точка входа, авто-отправка при публикации/обновлении, WP-Cron
├── uninstall.php                  # полная очистка данных при удалении плагина
├── includes/
│   ├── class-mii-settings.php     # страница настроек, Settings API, санитизация
│   ├── class-mii-ajax.php         # AJAX-обработчики (nonce + manage_options)
│   ├── class-mii-indexnow.php     # модуль IndexNow + виртуальный файл ключа
│   ├── class-mii-google.php       # Google Indexing API, JWT, дневная квота, очередь
│   ├── class-mii-logger.php       # логи в файл + таблица последних 20 записей
│   └── class-mii-crypto.php       # шифрование JSON сервисного аккаунта
└── assets/
    ├── css/admin.css              # стили страницы настроек
    └── js/admin.js                # AJAX, прогресс-бар, кнопки проверок
```

## Безопасность

- Все формы — через Settings API (`settings_fields()` → nonce, `options.php` → проверка прав).
- Все AJAX-запросы — `check_ajax_referer()` + `current_user_can( 'manage_options' )`.
- JSON сервисного аккаунта хранится в отдельной опции (`autoload = false`) **в зашифрованном виде**
  (AES-256-CBC + HMAC-SHA256, ключ — из солей WordPress) и никогда не выводится на страницу.
- Логи не содержат секретов: приватный ключ, JWT и access_token маскируются.
- Файл логов защищён `.htaccess` и `index.php`; физический файл ключа — только `/{ключ}.txt`.

## Что делать при проблемах

| Симптом | Причина и решение |
|---|---|
| IndexNow 403/404 | Файл ключа не открывается: включите «красивые ссылки», очистите кэш или создайте физический файл. |
| IndexNow 422 | URL не принадлежит домену сайта (проверьте «Настройки → Общие» и `www`). |
| IndexNow 202 | Ключ ещё проверяется — плагин повторит запрос автоматически. |
| Google 403 | Email сервисного аккаунта не добавлен в Search Console владельцем или не включён Web Search Indexing API. |
| Google 429 | Дневная квота (200): URL встанут в очередь и уйдут автоматически. |
| «Не удалось расшифровать JSON» | Сменились соли в `wp-config.php` — загрузите JSON заново. |
